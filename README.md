# clocktoml

Clock lightweight toml statistics from stdin samples.

**Site:** https://theworker02.github.io/clocktoml/

## Install / run

```bash
git clone https://github.com/theworker02/clocktoml.git
cd clocktoml
node src/cli.js
node --test
```
